# 需求规格说明书

## 1. 项目概述

### 1.1 项目名称
抽烟小助手 (Smoking Assistant)

### 1.2 项目简介
一个极简的网页应用，帮助用户记录抽烟行为、统计抽烟数据，并提供简单的戒烟提醒功能。

### 1.3 目标用户
希望控制或减少抽烟频率的用户

## 2. 功能需求

### 2.1 核心功能

#### 功能点 1：抽烟记录
- 描述：用户可以记录每次抽烟的时间
- 优先级：高
- 前置条件：用户访问网页
- 操作流程：点击"记录抽烟"按钮
- 预期结果：系统记录当前时间，更新统计数据

#### 功能点 2：数据统计
- 描述：显示今日抽烟次数、最近一次抽烟时间、平均抽烟间隔
- 优先级：高
- 前置条件：用户至少记录过一次抽烟
- 操作流程：自动计算并显示
- 预期结果：直观展示抽烟数据

#### 功能点 3：目标设置
- 描述：用户可以设置每日抽烟目标（最大次数）
- 优先级：中
- 前置条件：用户访问网页
- 操作流程：输入目标值并保存
- 预期结果：系统根据目标提供进度反馈

#### 功能点 4：数据重置
- 描述：用户可以重置当天的统计数据
- 优先级：低
- 前置条件：有统计数据
- 操作流程：点击"重置数据"按钮
- 预期结果：清空当天的所有记录

### 2.2 用户交互

#### 用户角色
| 角色 | 描述 | 权限 |
|------|------|------|
| 普通用户 | 使用抽烟小助手的用户 | 记录抽烟、查看统计、设置目标、重置数据 |

#### 界面原型（文字描述）
1. 顶部标题区域：显示应用名称
2. 统计显示区域：显示今日抽烟次数、最近抽烟时间、平均间隔
3. 目标设置区域：显示/设置每日抽烟目标
4. 操作按钮区域：包含"记录抽烟"和"重置数据"按钮
5. 历史记录区域：显示当天的抽烟时间记录列表

## 3. 数据需求

### 3.1 数据实体

| 实体名称 | 说明 | 主要属性 |
|----------|------|----------|
| 抽烟记录 | 每次抽烟的时间记录 | id, timestamp, date |
| 用户设置 | 用户的目标设置 | daily_target |

### 3.2 数据操作

| 操作 | 输入 | 输出 | 约束 |
|------|------|------|------|
| 添加记录 | 当前时间 | 新记录ID | 无 |
| 查询今日记录 | 当前日期 | 记录列表 | 按时间倒序 |
| 统计今日数据 | 当前日期 | 统计信息 | 计算次数、平均间隔 |
| 更新目标 | 目标值 | 成功状态 | 目标值必须为正整数 |

## 4. 非功能需求

### 4.1 性能需求
- 响应时间：页面加载 < 2秒
- 操作响应：按钮点击 < 500ms
- 数据存储：使用浏览器localStorage，无需服务器

### 4.2 安全需求
- 数据隐私：所有数据存储在用户本地浏览器
- 无用户认证：单用户本地使用

### 4.3 部署需求
- 运行环境：现代浏览器（Chrome/Firefox/Safari/Edge）
- 依赖服务：无服务器依赖，纯前端应用

## 5. 验收标准

### 5.1 功能验收
- [ ] 点击"记录抽烟"按钮能正确记录时间
- [ ] 统计数据能正确显示和更新
- [ ] 目标设置能保存并生效
- [ ] 重置功能能清空当天数据
- [ ] 页面刷新后数据不丢失

### 5.2 质量标准
- 页面加载时间 < 2秒
- 支持主流现代浏览器
- 代码结构清晰，易于维护
- 界面简洁直观，操作简单
