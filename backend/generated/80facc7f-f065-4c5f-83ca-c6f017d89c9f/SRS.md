# 需求规格说明书

## 1. 项目概述

### 1.1 项目名称
单词记忆助手（WordMaster）

### 1.2 项目简介
一个基于SpringBoot后端和UniApp前端的背单词小程序，提供多种学习模式，集成网易有道词典API获取单词释义和发音，帮助用户高效记忆英语单词。

### 1.3 目标用户
- 英语学习者（学生、职场人士）
- 备考各类英语考试的用户（四六级、考研、雅思、托福等）
- 日常英语提升者

## 2. 功能需求

### 2.1 核心功能

#### 功能点 1：用户注册登录
- 描述：用户可以通过手机号或邮箱注册登录，无需复杂认证
- 优先级：高
- 前置条件：无
- 操作流程：
  1. 用户进入注册页面
  2. 输入用户名、密码、邮箱/手机号
  3. 提交注册信息
  4. 系统验证信息并创建账户
  5. 用户登录系统
- 预期结果：用户成功注册并登录系统

#### 功能点 2：单词查询与学习
- 描述：用户输入单词，系统通过网易API获取单词详细信息
- 优先级：高
- 前置条件：用户已登录
- 操作流程：
  1. 用户在搜索框输入单词
  2. 系统调用网易有道词典API
  3. 获取单词的释义、音标、发音、例句等信息
  4. 展示单词详情页面
  5. 用户可以将单词加入学习计划
- 预期结果：用户获得完整的单词学习资料

#### 功能点 3：卡片学习模式
- 描述：以卡片形式展示单词，支持翻转查看释义
- 优先级：高
- 前置条件：用户有学习计划中的单词
- 操作流程：
  1. 用户选择卡片学习模式
  2. 系统展示单词卡片（正面显示单词）
  3. 用户点击卡片翻转查看释义
  4. 用户标记掌握程度（认识/不认识）
  5. 系统根据标记调整复习频率
- 预期结果：用户通过卡片记忆单词

#### 功能点 4：选择题测试
- 描述：提供选择题形式的单词测试
- 优先级：中
- 前置条件：用户有学习计划中的单词
- 操作流程：
  1. 用户选择选择题测试模式
  2. 系统展示单词和4个中文释义选项
  3. 用户选择正确答案
  4. 系统立即反馈正误并显示解析
  5. 记录用户的答题情况
- 预期结果：用户通过测试巩固单词记忆

#### 功能点 5：拼写练习
- 描述：根据中文释义拼写英文单词
- 优先级：中
- 前置条件：用户有学习计划中的单词
- 操作流程：
  1. 用户选择拼写练习模式
  2. 系统展示中文释义和首字母提示
  3. 用户输入英文单词
  4. 系统检查拼写正确性
  5. 提供发音播放功能
- 预期结果：用户通过拼写加深单词记忆

#### 功能点 6：单词收藏管理
- 描述：用户可以收藏重要单词，创建个人词库
- 优先级：中
- 前置条件：用户已登录
- 操作流程：
  1. 用户在单词详情页点击收藏按钮
  2. 单词加入个人收藏夹
  3. 用户可以查看、管理收藏的单词
  4. 可以对收藏的单词进行分类
- 预期结果：用户建立个人专属词库

#### 功能点 7：学习进度跟踪
- 描述：记录用户的学习数据，展示学习报告
- 优先级：中
- 前置条件：用户已登录并有学习记录
- 操作流程：
  1. 系统自动记录用户的学习行为
  2. 统计已学习单词数、掌握程度
  3. 生成每日、每周学习报告
  4. 展示学习曲线和进步情况
- 预期结果：用户了解自己的学习进度和效果

#### 功能点 8：智能复习计划
- 描述：基于艾宾浩斯遗忘曲线安排复习
- 优先级：中
- 前置条件：用户有学习记录
- 操作流程：
  1. 系统根据用户学习时间自动安排复习
  2. 在遗忘临界点提醒用户复习
  3. 动态调整复习频率
  4. 提供今日复习任务列表
- 预期结果：用户科学高效地复习单词

### 2.2 用户交互

#### 用户角色
| 角色 | 描述 | 权限 |
|------|------|------|
| 普通用户 | 英语学习者 | 注册登录、单词学习、收藏管理、查看进度 |
| 游客 | 未注册用户 | 单词查询、体验基础功能 |

#### 界面原型（文字描述）
1. **首页**：搜索框、学习模式入口、今日任务、学习统计
2. **学习页面**：卡片学习、选择题、拼写练习等模式切换
3. **单词详情页**：单词、音标、释义、例句、发音按钮、收藏按钮
4. **我的页面**：个人信息、我的收藏、学习报告、设置
5. **搜索页面**：搜索历史、热门搜索、搜索结果列表

## 3. 数据需求

### 3.1 数据实体

| 实体名称 | 说明 | 主要属性 |
|----------|------|----------|
| 用户 | 系统用户信息 | id, username, password, email, phone, avatar, created_at |
| 单词 | 单词基本信息 | id, word, phonetic, definition, example, audio_url, source |
| 用户单词 | 用户与单词的关联关系 | id, user_id, word_id, mastery_level, last_reviewed, next_review, added_at |
| 收藏夹 | 用户收藏的单词 | id, user_id, word_id, category, notes, created_at |
| 学习记录 | 用户学习行为记录 | id, user_id, word_id, mode, result, time_spent, created_at |
| 学习计划 | 用户的学习计划 | id, user_id, daily_goal, current_streak, total_days, created_at |

### 3.2 数据操作

| 操作 | 输入 | 输出 | 约束 |
|------|------|------|------|
| 用户注册 | 用户名、密码、邮箱 | 用户ID、token | 用户名唯一，邮箱格式正确 |
| 用户登录 | 用户名/邮箱、密码 | 用户信息、token | 密码验证通过 |
| 单词查询 | 单词 | 单词详情 | 调用网易API获取数据 |
| 添加学习 | 用户ID、单词ID | 成功状态 | 用户已登录，单词存在 |
| 记录学习 | 用户ID、单词ID、模式、结果 | 记录ID | 用户已登录，单词在学习计划中 |
| 收藏单词 | 用户ID、单词ID | 收藏ID | 用户已登录，单词未收藏 |
| 获取复习列表 | 用户ID | 单词列表 | 基于遗忘曲线算法 |

## 4. 非功能需求

### 4.1 性能需求
- 响应时间：API响应时间 < 500ms
- 并发能力：支持1000并发用户
- 单词查询：网易API调用响应时间 < 1s

### 4.2 安全需求
- 认证方式：JWT Token
- 权限控制：用户只能访问自己的数据
- 数据保护：密码加密存储（BCrypt）

### 4.3 部署需求
- 运行环境：Docker容器化部署
- 后端：SpringBoot 2.7+，Java 11+
- 前端：UniApp，HBuilderX开发
- 数据库：MySQL 8.0+
- 缓存：Redis（可选，用于缓存单词数据）

### 4.4 外部集成
- 网易有道词典API：用于获取单词释义和发音
- 第三方登录（可选）：微信登录、QQ登录
