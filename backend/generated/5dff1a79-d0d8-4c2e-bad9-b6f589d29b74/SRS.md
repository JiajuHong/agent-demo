# 需求规格说明书

## 1. 项目概述

### 1.1 项目名称
单词记忆助手（WordMaster）

### 1.2 项目简介
一个基于SpringBoot+UniApp的跨平台背单词小程序，提供多种学习模式、智能复习算法和丰富的单词资源，帮助用户高效记忆英语单词。

### 1.3 目标用户
- 学生群体（备考四六级、考研、托福、雅思）
- 职场人士（提升英语能力）
- 英语爱好者
- 所有需要记忆英语单词的用户

## 2. 功能需求

### 2.1 核心功能

#### 功能点 1：用户管理
- 描述：用户注册、登录、个人信息管理
- 优先级：高
- 前置条件：无
- 操作流程：
  1. 用户打开小程序
  2. 选择注册/登录
  3. 填写基本信息（用户名、密码）
  4. 进入主界面
- 预期结果：用户成功注册/登录，系统记录用户信息

#### 功能点 2：单词学习
- 描述：多种模式学习单词
- 优先级：高
- 前置条件：用户已登录
- 操作流程：
  1. 用户选择学习模式（卡片学习、选择题测试、拼写测试）
  2. 系统展示单词及信息（英文、音标、中文释义、例句）
  3. 用户点击发音按钮可听单词读音
  4. 用户标记单词掌握程度
- 预期结果：用户完成单词学习，系统记录学习进度

#### 功能点 3：智能复习
- 描述：基于遗忘曲线的智能复习系统
- 优先级：高
- 前置条件：用户有学习记录
- 操作流程：
  1. 系统根据用户学习历史和遗忘曲线算法推荐复习单词
  2. 用户进行复习测试
  3. 系统更新单词的记忆强度
- 预期结果：用户有效复习薄弱单词，提高记忆效率

#### 功能点 4：词库管理
- 描述：管理不同类别的单词词库
- 优先级：中
- 前置条件：用户已登录
- 操作流程：
  1. 用户查看可用词库列表（四级、六级、考研、托福等）
  2. 用户选择词库开始学习
  3. 用户可查看词库学习进度
- 预期结果：用户选择适合的词库进行学习

#### 功能点 5：学习统计
- 描述：查看学习数据统计
- 优先级：中
- 前置条件：用户有学习记录
- 操作流程：
  1. 用户进入统计页面
  2. 查看今日学习数据（学习单词数、复习单词数）
  3. 查看历史学习趋势图
  4. 查看掌握程度分布
- 预期结果：用户了解自己的学习进度和效果

#### 功能点 6：单词搜索
- 描述：搜索单词详细信息
- 优先级：低
- 前置条件：无
- 操作流程：
  1. 用户在搜索框输入单词
  2. 系统调用网易接口获取单词详细信息
  3. 展示单词释义、例句、发音等
- 预期结果：用户获取单词的详细信息

### 2.2 用户交互

#### 用户角色
| 角色 | 描述 | 权限 |
|------|------|------|
| 普通用户 | 注册用户 | 单词学习、复习、查看统计、管理词库 |

#### 界面原型（文字描述）
1. **登录/注册页**：简洁的表单页面，包含用户名、密码输入框
2. **主界面**：底部导航栏（学习、复习、词库、统计、我的）
3. **学习页面**：单词卡片展示区，包含单词、音标、释义、例句、发音按钮
4. **复习页面**：复习任务列表，按遗忘曲线排序
5. **词库页面**：词库分类列表，显示学习进度
6. **统计页面**：图表展示学习数据，包括日/周/月统计
7. **个人中心**：用户信息、设置、退出登录

## 3. 数据需求

### 3.1 数据实体

| 实体名称 | 说明 | 主要属性 |
|----------|------|----------|
| 用户 | 系统用户 | id, username, password, nickname, avatar, created_time |
| 单词 | 单词基本信息 | id, word, phonetic, definition, example, difficulty |
| 词库 | 单词分类集合 | id, name, description, total_words, category |
| 学习记录 | 用户学习单词记录 | id, user_id, word_id, mastery_level, last_review_time, next_review_time, review_count |
| 学习统计 | 用户学习统计数据 | id, user_id, date, learned_count, reviewed_count, total_time |

### 3.2 数据操作

| 操作 | 输入 | 输出 | 约束 |
|------|------|------|------|
| 用户注册 | username, password | 用户信息 | 用户名不能重复 |
| 用户登录 | username, password | 登录token | 密码需加密验证 |
| 获取单词 | word_id | 单词详细信息 | 无 |
| 记录学习 | user_id, word_id, mastery | 学习记录ID | 用户必须存在 |
| 获取复习列表 | user_id | 需要复习的单词列表 | 按遗忘曲线算法排序 |
| 获取统计 | user_id, date_range | 统计数据 | 支持按日/周/月统计 |

## 4. 非功能需求

### 4.1 性能需求
- 响应时间：API响应时间 < 200ms
- 并发能力：支持1000并发用户
- 吞吐量：QPS > 100

### 4.2 安全需求
- 认证方式：简单Token认证
- 权限控制：用户只能访问自己的数据
- 数据保护：密码加密存储（BCrypt）

### 4.3 部署需求
- 运行环境：Docker容器化部署
- 依赖服务：MySQL 8.0+、Redis缓存
- 外部接口：网易有道词典API
