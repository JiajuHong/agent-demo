# 需求规格说明书

## 1. 项目概述

### 1.1 项目名称
赛博朋克贪吃蛇游戏

### 1.2 项目简介
一个基于Java Swing开发的贪吃蛇游戏，采用赛博朋克风格设计，包含基本游戏功能，运行在Windows平台。

### 1.3 目标用户
- 喜欢经典贪吃蛇游戏的玩家
- 对赛博朋克风格感兴趣的用户
- 需要在Windows平台运行的Java游戏用户

## 2. 功能需求

### 2.1 核心功能

#### 功能点 1：游戏开始与暂停
- 描述：玩家可以开始新游戏、暂停游戏、继续游戏
- 优先级：高
- 前置条件：游戏已加载
- 操作流程：
  1. 点击"开始游戏"按钮开始新游戏
  2. 点击"暂停"按钮暂停游戏
  3. 点击"继续"按钮继续游戏
- 预期结果：游戏状态正确切换

#### 功能点 2：蛇的移动控制
- 描述：使用键盘方向键控制蛇的移动方向
- 优先级：高
- 前置条件：游戏正在进行中
- 操作流程：
  1. 按↑键：向上移动
  2. 按↓键：向下移动
  3. 按←键：向左移动
  4. 按→键：向右移动
- 预期结果：蛇按照指定方向移动

#### 功能点 3：食物生成与食用
- 描述：随机生成食物，蛇吃到食物后增长并得分
- 优先级：高
- 前置条件：游戏正在进行中
- 操作流程：
  1. 游戏开始时随机生成食物
  2. 蛇头碰到食物时，食物被吃掉
  3. 蛇身长度增加1
  4. 分数增加
  5. 在新位置生成新食物
- 预期结果：蛇正确吃到食物并增长

#### 功能点 4：碰撞检测
- 描述：检测蛇是否撞到墙壁或自身
- 优先级：高
- 前置条件：游戏正在进行中
- 操作流程：
  1. 蛇头碰到游戏区域边界
  2. 蛇头碰到蛇身任何部分
- 预期结果：游戏结束，显示游戏结束界面

#### 功能点 5：计分系统
- 描述：记录当前分数和最高分
- 优先级：中
- 前置条件：游戏正在进行中
- 操作流程：
  1. 每吃一个食物增加10分
  2. 游戏结束时保存最高分
  3. 显示当前分数和最高分
- 预期结果：分数正确计算和显示

### 2.2 用户交互

#### 用户角色
| 角色 | 描述 | 权限 |
|------|------|------|
| 玩家 | 游戏操作者 | 控制蛇移动、开始/暂停游戏、查看分数 |

#### 界面原型（文字描述）
1. 主游戏区域：
   - 赛博朋克风格背景（深色背景，霓虹灯效果）
   - 网格化的游戏区域
   - 蛇身：青色霓虹灯效果
   - 蛇头：亮青色，更明显
   - 食物：粉色或紫色霓虹灯效果

2. 控制面板：
   - 开始/暂停/继续按钮：蓝色霓虹灯效果
   - 分数显示：绿色数字，赛博朋克字体
   - 最高分显示：黄色数字，赛博朋克字体
   - 游戏状态显示

3. 游戏结束界面：
   - 半透明黑色背景
   - 红色"GAME OVER"文字
   - 最终分数显示
   - 重新开始按钮

## 3. 数据需求

### 3.1 数据实体

| 实体名称 | 说明 | 主要属性 |
|----------|------|----------|
| 蛇 | 游戏中的蛇 | 身体坐标列表、移动方向、长度 |
| 食物 | 游戏中的食物 | 坐标位置、是否被吃掉 |
| 游戏状态 | 游戏当前状态 | 是否运行、是否暂停、是否结束 |
| 分数 | 游戏分数 | 当前分数、最高分 |

### 3.2 数据操作

| 操作 | 输入 | 输出 | 约束 |
|------|------|------|------|
| 移动蛇 | 方向键输入 | 更新蛇位置 | 不能反向移动 |
| 生成食物 | 无 | 新食物坐标 | 不能生成在蛇身上 |
| 检测碰撞 | 蛇头坐标 | 碰撞结果 | 实时检测 |
| 更新分数 | 食物被吃 | 新分数 | 每次+10分 |

## 4. 非功能需求

### 4.1 性能需求
- 响应时间：键盘响应延迟 < 50ms
- 游戏帧率：稳定在30-60 FPS
- 内存使用：< 100MB

### 4.2 安全需求
- 无网络功能，本地运行安全
- 文件操作：仅读写本地最高分记录文件

### 4.3 部署需求
- 运行环境：Windows + Java 8或更高版本
- 依赖：仅需Java运行时环境
- 打包方式：可执行JAR文件

## 5. 验收标准

### 5.1 功能验收
- [ ] 游戏可以正常开始、暂停、继续
- [ ] 蛇可以通过方向键控制移动
- [ ] 蛇吃到食物后长度增加并得分
- [ ] 撞墙或撞自身后游戏结束
- [ ] 分数正确计算和显示
- [ ] 最高分正确保存和读取

### 5.2 质量标准
- 游戏运行流畅，无卡顿
- 界面符合赛博朋克风格设计
- 代码结构清晰，易于维护
- 无内存泄漏问题
