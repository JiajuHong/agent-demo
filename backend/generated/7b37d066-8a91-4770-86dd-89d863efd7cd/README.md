# 命令行计算器\n\n一个基于命令行的简单计算器程序，支持基本的四则运算，提供直观的交互界面。\n\n## 功能特性\n\n- ✅ 基本四则运算：加法、减法、乘法、除法\n- ✅ 连续计算：支持使用上一次计算结果\n- ✅ 错误处理：友好的错误提示，防止程序崩溃\n- ✅ 多语言支持：支持中文和英文的是/否选择\n- ✅ 格式化输出：美观的计算结果显示\n\n## 快速开始\n\n### 环境要求\n- Python 3.6 或更高版本\n\n### 安装运行\n\n1. 克隆或下载项目\n```bash\ngit clone <项目地址>\ncd calculator\n```\n\n2. 运行计算器\n```bash\n# 直接运行\npython src/main.py\n\n# 或添加执行权限后运行\nchmod +x src/main.py\n./src/main.py\n```\n\n## 使用示例\n\n```\n=== 命令行计算器 v1.0 ===\n\n欢迎使用命令行计算器！\n支持的操作: 加法(+), 减法(-), 乘法(*), 除法(/)\n输入 'Ctrl+C' 可随时退出程序\n----------------------------------------\n请输入第一个数字: 10\n请选择运算符 (+, -, *, /): +\n请输入第二个数字: 5\n\n========================================\n计算结果: 10 + 5 = 15\n========================================\n整数形式: 15\n计算时间: 2024-01-15 10:30:00\n\n是否继续计算? (y/n): y\n使用上一次结果(15)作为第一个数字? (y/n): n\n请输入第一个数字: 20\n请选择运算符 (+, -, *, /): *\n请输入第二个数字: 3\n\n========================================\n计算结果: 20 * 3 = 60\n========================================\n整数形式: 60\n计算时间: 2024-01-15 10:30:05\n\n是否继续计算? (y/n): n\n\n========================================\n感谢使用命令行计算器！\n再见！\n========================================\n```\n\n## 项目结构\n\n```\ncalculator/\n├── src/                    # 源代码目录\n│   ├── main.py            # 主程序入口\n│   ├── calculator.py      # 计算器核心类\n│   ├── input_handler.py   # 输入处理模块\n│   ├── calculator_engine.py # 计算引擎模块\n│   └── output_formatter.py # 输出格式化模块\n├── tests/                 # 测试目录\n│   ├── test_calculator_engine.py\n│   └── test_input_handler.py\n├── requirements.txt       # 依赖文件\n├── README.md             # 项目说明\n├── SRS.md                # 需求规格说明书\n├── DESIGN.md             # 软件设计文档\n└── .gitignore            # Git忽略文件\n```\n\n## 模块说明\n\n### 1. Calculator (计算器核心)\n- 控制整体计算流程\n- 管理计算状态和历史\n- 协调各模块工作\n\n### 2. InputHandler (输入处理)\n- 验证用户输入的有效性\n- 处理数字、运算符、是/否选择\n- 提供友好的错误提示\n\n### 3. CalculatorEngine (计算引擎)\n- 执行数学计算\n- 支持加减乘除四种运算\n- 处理除零等数学错误\n\n### 4. OutputFormatter (输出格式化)\n- 格式化显示计算结果\n- 显示欢迎和退出信息\n- 美化输出界面\n\n## 运行测试\n\n```bash\n# 运行所有测试\npython -m unittest discover tests\n\n# 运行特定测试模块\npython -m unittest tests.test_calculator_engine\npython -m unittest tests.test_input_handler\n```\n\n## 开发指南\n\n### 添加新功能\n1. 在 `SRS.md` 中添加需求描述\n2. 在 `DESIGN.md` 中更新设计\n3. 实现相应模块代码\n4. 添加单元测试\n5. 更新文档\n\n### 代码规范\n- 遵循 PEP 8 编码规范\n- 使用有意义的变量名\n- 添加必要的注释\n- 编写单元测试\n\n## 错误处理\n\n程序会处理以下错误情况：\n- 非数字输入\n- 无效运算符\n- 除零错误\n- 空输入\n\n遇到错误时，程序会显示友好的错误信息并允许用户重新输入。\n\n## 许可证\n\n本项目仅供学习和演示使用。\n\n## 贡献\n\n欢迎提交 Issue 和 Pull Request 来改进这个项目。\n\n## 联系方式\n\n如有问题或建议，请通过项目 Issue 页面联系。
