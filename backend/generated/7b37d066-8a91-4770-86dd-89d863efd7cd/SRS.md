# 需求规格说明书

## 1. 项目概述

### 1.1 项目名称
命令行计算器程序

### 1.2 项目简介
一个基于命令行的简单计算器程序，支持基本的四则运算，提供直观的交互界面，方便用户在终端中进行数学计算。

### 1.3 目标用户
- 需要在终端中进行快速计算的开发人员
- 学习编程的学生
- 需要简单计算工具的用户

## 2. 功能需求

### 2.1 核心功能

#### 功能点 1：基本四则运算
- 描述：支持加法、减法、乘法、除法四种基本运算
- 优先级：高
- 前置条件：程序已启动
- 操作流程：
  1. 用户输入第一个数字
  2. 用户选择运算符（+、-、*、/）
  3. 用户输入第二个数字
  4. 程序显示计算结果
- 预期结果：正确计算并显示结果

#### 功能点 2：连续计算
- 描述：支持连续多次计算，不清除历史结果
- 优先级：中
- 前置条件：已完成一次计算
- 操作流程：
  1. 用户可以选择继续使用上一次结果进行计算
  2. 或开始新的计算
- 预期结果：支持连续计算流程

#### 功能点 3：错误处理
- 描述：处理无效输入和数学错误
- 优先级：高
- 前置条件：用户输入了无效数据
- 操作流程：
  1. 检测无效输入（非数字、除零错误等）
  2. 显示友好的错误信息
  3. 允许用户重新输入
- 预期结果：程序不会崩溃，提供错误提示

### 2.2 用户交互

#### 用户角色
| 角色 | 描述 | 权限 |
|------|------|------|
| 计算用户 | 使用计算器进行数学运算 | 输入数字、选择运算符、查看结果 |

#### 界面原型（文字描述）
```
=== 命令行计算器 ===
欢迎使用计算器程序！

请输入第一个数字: 10
请选择运算符 (+, -, *, /): +
请输入第二个数字: 5
计算结果: 10 + 5 = 15

是否继续计算? (y/n): y
使用上一次结果(15)作为第一个数字? (y/n): n
请输入第一个数字: 20
请选择运算符 (+, -, *, /): *
请输入第二个数字: 3
计算结果: 20 * 3 = 60

是否继续计算? (y/n): n
感谢使用！
```

## 3. 数据需求

### 3.1 数据实体

| 实体名称 | 说明 | 主要属性 |
|----------|------|----------|
| 计算表达式 | 用户输入的计算表达式 | 操作数1, 运算符, 操作数2, 结果 |
| 计算历史 | 计算记录 | 表达式, 结果, 时间戳 |

### 3.2 数据操作

| 操作 | 输入 | 输出 | 约束 |
|------|------|------|------|
| 加法 | 两个数字 | 和 | 无 |
| 减法 | 两个数字 | 差 | 无 |
| 乘法 | 两个数字 | 积 | 无 |
| 除法 | 两个数字 | 商 | 除数不能为0 |

## 4. 非功能需求

### 4.1 性能需求
- 响应时间：单次计算 < 100ms
- 并发能力：单用户
- 吞吐量：不适用

### 4.2 安全需求
- 认证方式：无需认证
- 权限控制：无需权限控制
- 数据保护：无需特殊保护

### 4.3 部署需求
- 运行环境：Python 3.6+ 环境
- 依赖服务：无外部依赖
