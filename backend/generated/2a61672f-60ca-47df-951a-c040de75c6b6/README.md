# 极简TodoList应用

一个最简单的TodoList应用，包含最基本的功能，没有过度设计和复杂样式。

## 功能特性

### 核心功能
- ✅ **添加任务**：输入任务内容，点击添加或按回车键
- ✅ **显示任务**：以列表形式展示所有任务
- ✅ **完成任务**：点击复选框标记任务为已完成
- ✅ **删除任务**：点击删除按钮移除单个任务
- ✅ **任务统计**：显示总任务数、待完成数、已完成数
- ✅ **批量操作**：清除所有已完成任务或清除所有任务

### 数据存储
- 使用浏览器localStorage存储数据
- 刷新页面或关闭浏览器后数据不会丢失
- 支持跨会话数据持久化

### 用户体验
- 响应式设计，支持移动端和桌面端
- 简洁美观的界面设计
- 平滑的动画效果
- 操作反馈提示
- 键盘快捷键支持（回车添加任务）

## 使用说明

### 添加任务
1. 在输入框中输入任务内容
2. 点击"添加任务"按钮或按回车键
3. 任务将添加到列表顶部

### 管理任务
- **标记完成**：点击任务前的复选框
- **删除任务**：将鼠标悬停在任务上，点击右侧的"×"按钮
- **查看统计**：顶部显示任务统计信息

### 批量操作
- **清除已完成**：移除所有已完成的任务
- **清除所有**：清空所有任务（包括未完成）
