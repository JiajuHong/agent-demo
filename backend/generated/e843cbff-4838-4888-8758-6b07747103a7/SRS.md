# 需求规格说明书

## 1. 项目概述

### 1.1 项目名称
单词记忆助手

### 1.2 项目简介
一个基于Spring Boot后端和UniApp前端的背单词小程序，提供单词学习、复习、测试、进度跟踪等功能，集成网易有道词典API获取单词释义和发音。

### 1.3 目标用户
- 学生群体：备考四六级、考研、托福、雅思等
- 职场人士：提升英语能力，学习专业术语
- 英语爱好者：日常词汇积累和巩固

## 2. 功能需求

### 2.1 核心功能

#### 功能点 1：用户注册登录
- 描述：用户可以通过手机号或邮箱注册登录系统
- 优先级：高
- 前置条件：无
- 操作流程：
  1. 用户进入登录页面
  2. 选择注册或登录
  3. 输入手机号/邮箱和密码
  4. 完成验证后进入主界面
- 预期结果：用户成功登录系统，可以开始学习

#### 功能点 2：单词学习
- 描述：用户可以选择词库进行单词学习
- 优先级：高
- 前置条件：用户已登录
- 操作流程：
  1. 用户选择学习词库（如：四级、六级、考研等）
  2. 系统展示单词卡片（包含单词、音标、释义、例句）
  3. 用户可以点击播放单词发音
  4. 用户标记单词掌握程度（认识/模糊/不认识）
- 预期结果：用户学习新单词，系统记录学习进度

#### 功能点 3：单词复习
- 描述：根据艾宾浩斯遗忘曲线安排复习计划
- 优先级：高
- 前置条件：用户已学习过单词
- 操作流程：
  1. 系统根据学习记录推荐需要复习的单词
  2. 用户进行复习测试（选择题、拼写题等）
  3. 系统根据测试结果调整复习计划
- 预期结果：用户巩固已学单词，提高记忆效果

#### 功能点 4：单词测试
- 描述：多种形式的单词测试
- 优先级：中
- 前置条件：用户已学习过单词
- 操作流程：
  1. 用户选择测试类型（选择题、填空题、拼写题）
  2. 系统随机生成测试题目
  3. 用户完成测试并提交
  4. 系统给出测试结果和错题分析
- 预期结果：检验学习效果，发现薄弱环节

#### 功能点 5：学习进度跟踪
- 描述：可视化展示学习进度和统计数据
- 优先级：中
- 前置条件：用户已学习过单词
- 操作流程：
  1. 用户查看学习统计页面
  2. 系统展示：已学单词数、复习次数、正确率等
  3. 展示学习曲线和进步趋势
- 预期结果：用户了解自己的学习情况，调整学习计划

#### 功能点 6：词库管理
- 描述：管理内置词库和自定义词库
- 优先级：中
- 前置条件：用户已登录
- 操作流程：
  1. 用户查看内置词库列表
  2. 可以创建自定义词库
  3. 向自定义词库添加单词
  4. 导入/导出词库
- 预期结果：用户可以根据需求管理学习内容

#### 功能点 7：单词搜索
- 描述：通过网易有道词典API查询单词详情
- 优先级：低
- 前置条件：无
- 操作流程：
  1. 用户输入单词进行搜索
  2. 系统调用网易API获取单词详细信息
  3. 展示单词释义、发音、例句等
- 预期结果：用户获取单词的详细信息

### 2.2 用户交互

#### 用户角色
| 角色 | 描述 | 权限 |
|------|------|------|
| 普通用户 | 注册用户，使用学习功能 | 注册登录、单词学习、复习测试、查看进度 |
| 管理员 | 系统管理员 | 用户管理、词库管理、系统配置 |

#### 界面原型（文字描述）
1. **登录注册页**：简洁的表单，手机号/邮箱+密码输入框
2. **首页**：学习卡片、复习提醒、快速测试入口
3. **学习页**：单词卡片展示，包含发音按钮、掌握程度选择
4. **复习页**：测试题目展示，选择题/填空题形式
5. **统计页**：图表展示学习数据，进度条、趋势图
6. **词库页**：词库列表，分类展示，搜索功能

## 3. 数据需求

### 3.1 数据实体

| 实体名称 | 说明 | 主要属性 |
|----------|------|----------|
| 用户 | 系统用户信息 | id, username, email, password, create_time |
| 单词 | 单词基本信息 | id, word, phonetic, definition, example |
| 词库 | 单词集合 | id, name, type, description, word_count |
| 学习记录 | 用户学习单词的记录 | id, user_id, word_id, status, review_count, next_review_time |
| 测试记录 | 用户测试记录 | id, user_id, test_type, score, start_time, end_time |
| 错题本 | 用户错题记录 | id, user_id, word_id, error_type, error_count |

### 3.2 数据操作

| 操作 | 输入 | 输出 | 约束 |
|------|------|------|------|
| 用户注册 | 用户名、邮箱、密码 | 用户ID、token | 邮箱不能重复 |
| 用户登录 | 邮箱、密码 | 用户信息、token | 密码需加密存储 |
| 获取单词 | 单词ID或单词 | 单词详细信息 | 调用网易API获取实时数据 |
| 记录学习 | 用户ID、单词ID、状态 | 学习记录ID | 更新复习计划 |
| 开始测试 | 用户ID、测试类型 | 测试题目列表 | 根据学习进度生成题目 |
| 提交测试 | 用户ID、测试ID、答案 | 测试结果、错题记录 | 更新学习记录 |

## 4. 非功能需求

### 4.1 性能需求
- 响应时间：API响应时间 < 500ms
- 并发能力：支持1000并发用户
- 吞吐量：支持100 TPS

### 4.2 安全需求
- 认证方式：JWT Token
- 权限控制：用户只能访问自己的数据
- 数据保护：密码加密存储，敏感数据脱敏

### 4.3 部署需求
- 运行环境：Docker容器化部署
- 依赖服务：MySQL 8.0+、Redis缓存
- 外部API：网易有道词典API
