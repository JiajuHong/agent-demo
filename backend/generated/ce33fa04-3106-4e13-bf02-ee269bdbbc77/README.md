# 简单五子棋游戏

一个使用Python Tkinter实现的简单五子棋游戏，支持双人对战，包含基本的游戏功能和胜负判断。

## 功能特点

- 🎮 **双人对战**：支持两名玩家轮流落子，黑棋先行
- 🏆 **胜负判断**：自动检测五子连珠，宣布获胜方
- 🔄 **重新开始**：一键重置游戏状态
- 🎨 **简洁界面**：清晰的15x15棋盘，黑白棋子分明
- 📱 **易于使用**：鼠标点击即可落子，操作简单

## 系统要求

- Python 3.6 或更高版本
- Tkinter（Python标准库，通常已预装）

## 游戏规则

1. **棋盘**：15x15网格
2. **棋子**：黑棋和白棋
3. **顺序**：黑棋先行，然后黑白交替
4. **目标**：在横、竖、斜任意方向连成五子
5. **胜负**：先连成五子的一方获胜

## 操作说明

### 游戏界面

```
+-----------------------------------+

+-----------------------------------+
|                                   |

|          (15x15网格)              |
```

### 基本操作

1. **落子**：鼠标点击棋盘上的交叉点
2. **重新开始**：点击"重新开始"按钮重置游戏
3. **退出游戏**：关闭窗口或按Ctrl+C

### 游戏流程

1. 游戏启动后，黑棋先行
2. 玩家轮流点击棋盘落子
3. 当一方连成五子时，游戏结束并显示获胜信息
4. 点击"重新开始"按钮开始新游戏

### 代码架构

游戏采用MVC（Model-View-Controller）设计模式：

- **GameModel**：管理游戏数据状态（棋盘、当前玩家等）
- **GameController**：处理游戏逻辑和用户输入
- **GameView**：显示游戏界面和接收用户输入

## 技术细节

### 胜负判断算法

游戏使用高效的胜负判断算法：
- 每次落子后只检查周围8个方向
- 检查四个方向：水平、垂直、右斜、左斜
- 每个方向正反检查最多4步
- 时间复杂度：O(1)

### 坐标系统

- 棋盘坐标：0-14（15x15网格）
- 屏幕坐标：根据网格大小和边距计算
- 坐标转换：自动处理鼠标点击位置到棋盘坐标的转换

## 常见问题

### Q: 游戏无法启动
**A**: 确保已安装Python 3.6+，并且Tkinter可用。在命令行中运行 `python --version` 检查Python版本。

### Q: 点击棋盘没有反应
**A**: 请确保点击在交叉点上，而不是网格线上。如果游戏已结束，需要点击"重新开始"按钮。

### Q: 如何修改棋盘大小？
**A**: 在 `gomoku.py` 文件中修改 `GameModel` 的 `board_size` 参数。

### Q: 可以添加AI对手吗？
**A**: 当前版本只支持双人对战。可以扩展代码添加简单的AI算法。
