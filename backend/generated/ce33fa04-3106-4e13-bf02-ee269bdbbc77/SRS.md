# 需求规格说明书

## 1. 项目概述

### 1.1 项目名称
简单五子棋游戏

### 1.2 项目简介
一个使用Python Tkinter GUI库实现的简单五子棋游戏，支持双人对战，包含基本的游戏功能和胜负判断。

### 1.3 目标用户
- 想要学习Python GUI编程的开发者
- 需要简单五子棋游戏的用户
- 用于教学演示的简单游戏示例

## 2. 功能需求

### 2.1 核心功能

#### 功能点 1：游戏界面显示
- 描述：显示15x15的五子棋棋盘，黑白棋子交替落子
- 优先级：高
- 前置条件：程序启动
- 操作流程：
  1. 程序启动显示棋盘
  2. 棋盘网格清晰可见
  3. 棋子位置准确显示
- 预期结果：用户可以看到清晰的棋盘界面

#### 功能点 2：双人对战
- 描述：支持两名玩家轮流落子，黑棋先行
- 优先级：高
- 前置条件：游戏界面已显示
- 操作流程：
  1. 黑方玩家点击棋盘位置落子
  2. 自动切换为白方回合
  3. 白方玩家点击棋盘位置落子
  4. 重复交替直到游戏结束
- 预期结果：两名玩家可以轮流在棋盘上落子

#### 功能点 3：胜负判断
- 描述：自动判断是否有五子连珠，宣布获胜方
- 优先级：高
- 前置条件：有棋子落在棋盘上
- 操作流程：
  1. 每次落子后检查四个方向（横、竖、左斜、右斜）
  2. 如果某方有连续五个相同棋子，游戏结束
  3. 显示获胜信息
- 预期结果：游戏能正确判断胜负并结束

#### 功能点 4：游戏控制
- 描述：提供重新开始游戏功能
- 优先级：中
- 前置条件：游戏进行中或已结束
- 操作流程：
  1. 点击"重新开始"按钮
  2. 清空棋盘
  3. 重置游戏状态
- 预期结果：可以重新开始新游戏

### 2.2 用户交互

#### 用户角色
| 角色 | 描述 | 权限 |
|------|------|------|
| 玩家1（黑棋） | 控制黑棋落子 | 在棋盘上点击落黑棋 |
| 玩家2（白棋） | 控制白棋落子 | 在棋盘上点击落白棋 |

#### 界面原型（文字描述）
1. 主窗口：600x600像素的游戏窗口
2. 棋盘区域：15x15网格，黑色线条绘制
3. 棋子：黑色圆形（玩家1），白色圆形（玩家2）
4. 状态栏：显示当前回合玩家
5. 控制按钮："重新开始"按钮

## 3. 数据需求

### 3.1 数据实体

| 实体名称 | 说明 | 主要属性 |
|----------|------|----------|
| 棋盘状态 | 记录棋盘上每个位置的状态 | 15x15二维数组，0=空，1=黑棋，2=白棋 |
| 游戏状态 | 记录当前游戏状态 | 当前玩家（黑/白），游戏是否结束，获胜方 |

### 3.2 数据操作

| 操作 | 输入 | 输出 | 约束 |
|------|------|------|------|
| 落子 | 坐标(x,y)，玩家颜色 | 更新棋盘状态，切换玩家 | 位置必须在棋盘内且为空 |
| 检查胜负 | 棋盘状态，最后落子位置 | 是否获胜，获胜方 | 检查四个方向是否有五连 |
| 重置游戏 | 无 | 清空棋盘，重置状态 | 无 |

## 4. 非功能需求

### 4.1 性能需求
- 响应时间：落子响应 < 100ms
- 并发能力：单机双人游戏
- 棋盘渲染：流畅无卡顿

### 4.2 安全需求
- 无网络功能，无需安全认证
- 本地运行，数据不存储

### 4.3 部署需求
- 运行环境：Python 3.6+
- 依赖库：tkinter（Python标准库）
- 操作系统：Windows/macOS/Linux

## 5. 验收标准

### 5.1 功能验收
- [ ] 游戏界面正常显示15x15棋盘
- [ ] 黑白棋子可以交替落子
- [ ] 能正确判断五子连珠胜负
- [ ] "重新开始"按钮可以重置游戏
- [ ] 状态栏显示当前回合玩家

### 5.2 质量标准
- 代码文件不超过3个
- 总代码行数不超过500行
- 程序启动时间 < 2秒
- 无运行时错误
