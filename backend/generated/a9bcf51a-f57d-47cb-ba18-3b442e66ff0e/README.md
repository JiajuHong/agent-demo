# TodoList 任务管理器
12345
一个功能完整的纯前端TodoList任务管理应用，使用HTML、CSS和JavaScript实现。

## 功能特性

### 核心功能
- ✅ 添加新任务（支持优先级设置）
- ✅ 查看任务列表（支持排序）
- ✅ 标记任务完成状态
- ✅ 编辑任务内容
- ✅ 删除任务
- ✅ 过滤任务（全部/待完成/已完成）
- ✅ 搜索任务
- ✅ 数据持久化（使用localStorage）

### 高级功能
- 📊 任务统计（总任务数、已完成、待完成）
- 📤 任务导出（JSON格式）
- 📥 任务导入（JSON格式）
- 🧹 批量操作（清除已完成、清空所有）
- 📱 响应式设计（适配手机和电脑）
- 🎨 美观的UI界面

### 欢迎信息
- 页面加载时显示"hello world"欢迎信息

## 快速开始

### 方法一：直接打开
1. 下载项目文件
2. 双击 `index.html` 文件在浏览器中打开

### 方法二：本地服务器
1. 安装Python（如果已安装可跳过）
2. 在项目目录下运行：
   ```bash
   python -m http.server 8000
   ```
3. 浏览器访问 `http://localhost:8000`

### 方法三：使用Node.js
1. 安装Node.js
2. 安装 `http-server`：
   ```bash
   npm install -g http-server
   ```
3. 在项目目录下运行：
   ```bash
   http-server
   ```
4. 浏览器访问显示的地址

## 使用说明

### 添加任务
1. 在输入框中输入任务内容
2. 选择优先级（低/中/高）
3. 点击"添加任务"按钮或按Enter键

### 管理任务
- **标记完成**：点击任务前的复选框
- **编辑任务**：点击任务右侧的编辑按钮（铅笔图标）
- **删除任务**：点击任务右侧的删除按钮（垃圾桶图标）

### 过滤和搜索
- **过滤**：使用顶部的过滤按钮查看全部、待完成或已完成的任务
- **搜索**：在搜索框中输入关键词查找特定任务

### 批量操作
- **清除已完成**：移除所有已完成的任务
- **导出任务**：将当前所有任务导出为JSON文件
- **导入任务**：从JSON文件导入任务（会覆盖现有任务）
- **清空所有**：删除所有任务（谨慎操作）

## 数据存储

应用使用浏览器的localStorage存储任务数据，具有以下特点：
- 数据保存在本地浏览器中
- 刷新页面不会丢失数据
- 支持跨浏览器会话
- 每个域名独立存储

### 数据格式
```json
{
  "id": 1234567890,
  "title": "任务标题",
  "priority": "medium",
  "completed": false,
  "createdAt": "2024-01-01T00:00:00.000Z",
  "updatedAt": "2024-01-01T00:00:00.000Z"
}
```

## 故障排除

### 常见问题

1. **任务无法保存**
   - 检查浏览器是否支持localStorage
   - 检查浏览器是否启用了隐私模式
   - 清除浏览器缓存后重试

2. **样式显示不正常**
   - 检查网络连接，确保能访问Font Awesome和Google Fonts
   - 检查CSS文件是否正确加载

3. **导入任务失败**
   - 确保导入的JSON格式正确
   - 检查JSON数据是否包含有效的任务数组

### 调试方法
1. 打开浏览器开发者工具（F12）
2. 在Console面板查看错误信息
3. 在Application面板查看localStorage数据
