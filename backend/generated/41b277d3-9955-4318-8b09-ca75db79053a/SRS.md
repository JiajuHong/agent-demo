# 需求规格说明书

## 1. 项目概述

### 1.1 项目名称
单词记忆大师（WordMaster）

### 1.2 项目简介
一个基于SpringBoot的智能背单词Web应用，采用艾宾浩斯遗忘曲线算法，帮助用户高效记忆英语单词。系统提供个性化学习计划、进度跟踪和多种练习模式。

### 1.3 目标用户
- 英语学习者（学生、职场人士）
- 备考人员（托福、雅思、GRE等）
- 英语教师（可用于教学管理）

## 2. 功能需求

### 2.1 核心功能

#### 功能点 1：用户管理
- 描述：用户注册、登录、个人信息管理
- 优先级：高
- 前置条件：无
- 操作流程：
  1. 用户访问注册页面
  2. 填写用户名、邮箱、密码
  3. 系统发送验证邮件
  4. 用户验证后登录系统
- 预期结果：用户成功注册并登录系统

#### 功能点 2：单词库管理
- 描述：创建、编辑、删除单词库和单词
- 优先级：高
- 前置条件：用户已登录
- 操作流程：
  1. 用户创建单词库（如"四级词汇"、"商务英语"）
  2. 添加单词（英文、中文释义、音标、例句）
  3. 批量导入单词（支持Excel/CSV格式）
  4. 编辑或删除单词
- 预期结果：用户拥有个性化的单词库

#### 功能点 3：学习模式
- 描述：多种学习模式帮助记忆单词
- 优先级：高
- 前置条件：用户已登录且有单词库
- 操作流程：
  1. 用户选择学习模式（新学、复习、测试）
  2. 系统根据记忆曲线推送单词
  3. 用户进行学习（看词义、听发音、拼写练习）
  4. 系统记录学习结果
- 预期结果：用户完成当日学习任务

#### 功能点 4：复习系统
- 描述：基于艾宾浩斯遗忘曲线的智能复习
- 优先级：高
- 前置条件：用户已学习过单词
- 操作流程：
  1. 系统根据遗忘曲线计算复习时间点
  2. 在适当时机提醒用户复习
  3. 用户完成复习后更新记忆强度
  4. 系统调整后续复习计划
- 预期结果：提高单词记忆效率

#### 功能点 5：进度跟踪
- 描述：可视化学习进度和统计数据
- 优先级：中
- 前置条件：用户已学习过单词
- 操作流程：
  1. 用户查看学习仪表板
  2. 显示已学单词数、复习次数、记忆率
  3. 查看学习曲线图
  4. 导出学习报告
- 预期结果：用户了解自己的学习情况

#### 功能点 6：测试评估
- 描述：多种测试模式评估学习效果
- 优先级：中
- 前置条件：用户已学习过单词
- 操作流程：
  1. 用户选择测试类型（选择题、拼写题、听力题）
  2. 系统随机生成测试题目
  3. 用户完成测试
  4. 系统评分并给出分析报告
- 预期结果：评估用户单词掌握程度

### 2.2 用户交互

#### 用户角色
| 角色 | 描述 | 权限 |
|------|------|------|
| 普通用户 | 英语学习者 | 注册、登录、管理个人单词库、学习、测试 |
| 管理员 | 系统管理员 | 所有用户管理、系统配置、数据统计 |

#### 界面原型（文字描述）
1. **登录/注册页面**：简洁的表单，包含用户名/邮箱、密码输入框
2. **仪表板页面**：显示学习进度、今日任务、统计数据卡片
3. **单词库页面**：表格展示单词列表，支持搜索、筛选、批量操作
4. **学习页面**：卡片式单词展示，包含发音按钮、释义切换
5. **测试页面**：测试题目展示，计时器，提交按钮
6. **个人中心**：个人信息、学习设置、数据导出

## 3. 数据需求

### 3.1 数据实体

| 实体名称 | 说明 | 主要属性 |
|----------|------|----------|
| 用户 | 系统用户 | id, username, email, password, avatar, created_at |
| 单词库 | 单词集合 | id, name, description, user_id, word_count, created_at |
| 单词 | 单词信息 | id, word, phonetic, meaning, example, wordbook_id, created_at |
| 学习记录 | 单词学习记录 | id, user_id, word_id, status, memory_strength, next_review_time, review_count |
| 测试记录 | 测试结果记录 | id, user_id, test_type, score, duration, created_at |
| 复习计划 | 复习时间安排 | id, user_id, word_id, review_time, completed |

### 3.2 数据操作

| 操作 | 输入 | 输出 | 约束 |
|------|------|------|------|
| 用户注册 | username, email, password | 用户信息 | 邮箱唯一，密码加密存储 |
| 用户登录 | username/email, password | JWT Token | 验证密码正确性 |
| 创建单词库 | name, description | 单词库信息 | 用户必须登录 |
| 添加单词 | word, phonetic, meaning, example | 单词信息 | 单词不能重复 |
| 开始学习 | wordbook_id | 单词列表 | 按记忆强度排序 |
| 完成学习 | word_id, memory_strength | 学习记录 | 更新下次复习时间 |
| 开始测试 | test_type, word_count | 测试题目 | 随机选择单词 |
| 提交测试 | answers | 测试结果 | 自动评分 |

## 4. 非功能需求

### 4.1 性能需求
- 响应时间：API响应时间 < 200ms
- 并发能力：支持1000个并发用户
- 吞吐量：支持100 TPS

### 4.2 安全需求
- 认证方式：JWT Token
- 权限控制：基于角色的访问控制（RBAC）
- 数据保护：密码BCrypt加密，敏感数据脱敏

### 4.3 部署需求
- 运行环境：Docker容器化部署
- 依赖服务：MySQL 8.0、Redis缓存
- 服务器：Linux服务器，2核4G内存
