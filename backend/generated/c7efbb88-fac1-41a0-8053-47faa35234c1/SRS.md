# 需求规格说明书

## 1. 项目概述

### 1.1 项目名称
ROS1话题发布订阅Demo程序

### 1.2 项目简介
一个简单的ROS1（Robot Operating System）演示程序，包含一个发布者节点和一个订阅者节点，用于演示ROS话题通信机制。

### 1.3 目标用户
- ROS初学者
- 需要快速了解ROS话题通信的开发者
- 教学演示用途

## 2. 功能需求

### 2.1 核心功能

#### 功能点 1：话题发布者节点
- 描述：创建一个ROS节点，定期向指定话题发布消息
- 优先级：高
- 前置条件：ROS环境已安装并配置，roscore已启动
- 操作流程：
  1. 初始化ROS节点
  2. 创建话题发布者
  3. 设置发布频率（1Hz）
  4. 循环发布消息
- 预期结果：消息成功发布到指定话题

#### 功能点 2：话题订阅者节点
- 描述：创建一个ROS节点，订阅指定话题并处理接收到的消息
- 优先级：高
- 前置条件：ROS环境已安装并配置，roscore已启动
- 操作流程：
  1. 初始化ROS节点
  2. 创建话题订阅者
  3. 设置消息回调函数
  4. 等待并处理接收到的消息
- 预期结果：成功接收并处理发布者发送的消息

### 2.2 用户交互

#### 用户角色
| 角色 | 描述 | 权限 |
|------|------|------|
| 开发者 | 运行和测试程序 | 启动节点、查看日志 |

#### 界面原型（文字描述）
- 终端界面：通过终端命令启动节点
- ROS日志输出：在终端显示发布和接收的消息
- ROS话题查看：使用`rostopic echo`命令查看话题内容

## 3. 数据需求

### 3.1 数据实体

| 实体名称 | 说明 | 主要属性 |
|----------|------|----------|
| ROS消息 | 话题通信的数据载体 | data (字符串类型) |
| ROS节点 | 发布者或订阅者 | node_name, topic_name |
| ROS话题 | 消息传输通道 | topic_name, message_type |

### 3.2 数据操作

| 操作 | 输入 | 输出 | 约束 |
|------|------|------|------|
| 发布消息 | 字符串消息 | 无 | 消息必须符合std_msgs/String格式 |
| 订阅消息 | 无 | 字符串消息 | 回调函数必须正确处理消息 |
| 话题通信 | 发布者节点 | 订阅者节点 | 话题名称必须一致 |

## 4. 非功能需求

### 4.1 性能需求
- 响应时间：消息延迟 < 100ms
- 并发能力：支持多个订阅者同时订阅同一话题
- 吞吐量：1条消息/秒（可配置）

### 4.2 安全需求
- 认证方式：ROS内置节点认证
- 权限控制：无特殊权限要求
- 数据保护：消息内容明文传输

### 4.3 部署需求
- 运行环境：Ubuntu + ROS1（Noetic/Melodic）
- 依赖服务：roscore主节点
- 构建工具：catkin_make

## 5. 验收标准

### 5.1 功能验收
- [ ] 发布者节点可正常启动并发布消息
- [ ] 订阅者节点可正常启动并接收消息
- [ ] 消息内容正确传输
- [ ] 发布频率符合预期（1Hz）

### 5.2 质量标准
- 代码编译无错误
- ROS包结构完整
- 代码注释清晰
- 可独立运行两个节点
