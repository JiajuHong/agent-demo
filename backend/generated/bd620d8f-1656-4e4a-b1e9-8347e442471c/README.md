# 简单待办事项应用

一个极简的纯前端待办事项应用，使用 HTML、CSS 和 JavaScript 实现。

## 功能特性

- ✅ **添加任务**：快速添加新的待办事项
- ✅ **标记完成**：点击复选框标记任务为完成/未完成
- ✅ **删除任务**：删除单个任务
- ✅ **批量操作**：一键清除已完成任务或所有任务
- ✅ **数据持久化**：使用 localStorage 保存数据，刷新页面不丢失
- ✅ **任务统计**：实时显示任务完成情况统计
- ✅ **响应式设计**：适配桌面和移动设备
- ✅ **用户友好**：清晰的反馈和确认对话框

## 快速开始

1. 下载或克隆项目文件
2. 直接在浏览器中打开 `index.html` 文件
3. 开始使用待办事项应用

无需安装任何依赖，无需配置服务器！

## 使用说明

### 添加任务
1. 在输入框中输入任务内容
2. 点击"添加"按钮或按回车键
3. 任务将添加到列表顶部

### 管理任务
- **标记完成**：点击任务前的复选框
- **删除单个任务**：点击任务右侧的删除按钮
- **清除已完成任务**：点击"清除已完成"按钮
- **清除所有任务**：点击"清除所有"按钮

### 数据存储
- 所有数据存储在浏览器的 localStorage 中
- 数据仅在当前浏览器中有效
- 清除浏览器缓存会删除所有数据

## 技术实现

### 架构设计
- **数据层**：TodoService 类负责数据管理和持久化
- **UI层**：UIManager 类负责界面渲染和事件处理
- **存储**：使用 localStorage 实现数据持久化

### 核心模块
1. **TodoService**：数据服务模块
   - 任务增删改查
   - 数据持久化
   - 统计计算

2. **UIManager**：界面管理模块
   - DOM元素管理
   - 事件处理
   - 界面渲染
   - 用户反馈

### 安全特性
- HTML转义防止XSS攻击
- 输入验证和长度限制
- 操作确认对话框

## 故障排除

### 常见问题
1. **数据丢失**：检查浏览器是否启用了 localStorage
2. **界面错乱**：确保所有文件在同一目录下
3. **功能异常**：尝试清除浏览器缓存后重试

### 调试方法
1. 按 F12 打开开发者工具
2. 在 Console 标签页查看错误信息
3. 在 Application 标签页查看 localStorage 数据
