# 简单TodoList应用

一个最简单的TodoList应用，包含最基本的功能，没有复杂的设计和样式。

## 功能特性

- ✅ 添加新任务
- ✅ 显示任务列表
- ✅ 删除任务
- ✅ 数据持久化（使用浏览器localStorage）
- ✅ 响应式设计

## 使用方法

1. 直接双击打开 `index.html` 文件
2. 在输入框中输入任务内容
3. 点击"添加"按钮或按回车键添加任务
4. 点击任务旁边的"删除"按钮删除任务

## 文件结构

```
simple-todolist/
├── index.html      # 主HTML文件（包含所有代码）
└── README.md       # 说明文档
```

## 技术说明

- 纯HTML/CSS/JavaScript实现，无需安装任何依赖
- 使用浏览器localStorage存储数据，页面刷新后数据不丢失
- 支持键盘操作（回车键添加任务）
- 简单的响应式设计，适配不同屏幕尺寸

## 设计原则

1. **最简单**：只包含最基本的功能
2. **无冗余**：代码简洁，没有不必要的功能
3. **易使用**：界面直观，操作简单
4. **数据持久**：任务数据保存在浏览器中

## 浏览器兼容性

支持所有现代浏览器（Chrome, Firefox, Safari, Edge等）
