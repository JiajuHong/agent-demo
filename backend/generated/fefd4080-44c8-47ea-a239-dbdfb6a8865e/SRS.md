# 需求规格说明书

## 1. 项目概述

### 1.1 项目名称
Python 五子棋游戏

### 1.2 项目简介
一个简单的命令行五子棋游戏，支持两名玩家轮流对战，包含基本的游戏规则和胜负判断。

### 1.3 目标用户
- 想学习Python游戏开发的初学者
- 需要简单五子棋对战功能的用户
- 希望了解基本游戏逻辑的开发者

## 2. 功能需求

### 2.1 核心功能

#### 功能点 1：游戏初始化
- 描述：初始化15x15的棋盘，设置游戏状态
- 优先级：高
- 前置条件：程序启动
- 操作流程：自动执行
- 预期结果：棋盘清空，黑方先手

#### 功能点 2：棋盘显示
- 描述：在控制台显示当前棋盘状态
- 优先级：高
- 前置条件：游戏已初始化
- 操作流程：每次落子后自动显示
- 预期结果：清晰显示棋盘、棋子和坐标

#### 功能点 3：玩家落子
- 描述：玩家输入坐标落子
- 优先级：高
- 前置条件：轮到当前玩家
- 操作流程：
  1. 提示当前玩家（黑/白）
  2. 输入行号和列号（1-15）
  3. 检查位置是否合法
  4. 落子并更新棋盘
- 预期结果：棋子正确放置在指定位置

#### 功能点 4：胜负判断
- 描述：判断是否有五子连珠
- 优先级：高
- 前置条件：每次落子后
- 操作流程：检查横、竖、左斜、右斜四个方向
- 预期结果：正确判断胜负，宣布获胜方

#### 功能点 5：游戏结束处理
- 描述：游戏结束后的处理
- 优先级：中
- 前置条件：胜负已分或棋盘已满
- 操作流程：显示结果，询问是否重新开始
- 预期结果：游戏正常结束或重新开始

### 2.2 用户交互

#### 用户角色
| 角色 | 描述 | 权限 |
|------|------|------|
| 玩家1（黑棋） | 执黑棋的玩家 | 在轮到自己时落子 |
| 玩家2（白棋） | 执白棋的玩家 | 在轮到自己时落子 |


## 3. 数据需求

### 3.1 数据实体

| 实体名称 | 说明 | 主要属性 |
|----------|------|----------|
| 棋盘 | 15x15的游戏棋盘 | board[15][15] |
| 游戏状态 | 当前游戏状态 | current_player, game_over, winner |
| 棋子 | 棋盘上的棋子 | color, row, col |

### 3.2 数据操作

| 操作 | 输入 | 输出 | 约束 |
|------|------|------|------|
| 初始化棋盘 | 无 | 空棋盘 | 15x15大小 |
| 落子 | 行号, 列号, 颜色 | 更新后的棋盘 | 位置必须在棋盘内且为空 |
| 检查胜负 | 行号, 列号, 颜色 | 是否获胜 | 检查四个方向 |
| 显示棋盘 | 棋盘状态 | 格式化输出 | 清晰显示棋子和坐标 |

## 4. 非功能需求

### 4.1 性能需求
- 响应时间：落子后立即响应
- 并发能力：单机双人对战
- 棋盘大小：固定15x15

### 4.2 安全需求
- 输入验证：检查坐标范围
- 位置检查：防止重复落子

### 4.3 部署需求
- 运行环境：Python 3.6+
- 依赖：无外部依赖，仅使用Python标准库

### 5.1 功能验收
- [ ] 游戏可以正常启动和初始化
- [ ] 棋盘正确显示
- [ ] 玩家可以轮流落子
- [ ] 胜负判断准确
- [ ] 游戏结束处理正常
