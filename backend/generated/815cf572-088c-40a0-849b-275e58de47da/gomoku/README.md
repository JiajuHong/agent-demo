# 五子棋游戏 (Gomoku)

基于 PyQt5 的简单五子棋游戏，支持双人对战。

## 功能特点

- 🎮 双人对战模式
- 🏆 自动胜负判断
- 🔄 游戏重置功能
- 🎨 美观的棋盘界面
- 🖱️ 鼠标点击操作

## 运行要求

- Python 3.6 或更高版本
- PyQt5 库

## 安装和运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行游戏

```bash
# 方法一：直接运行主程序
python src/main.py

# 方法二：使用模块方式运行
python -m src.main
```

## 游戏规则

1. 棋盘大小为 15×15
2. 黑棋先行，双方轮流落子
3. 先在横、竖、斜任意方向连成五子者获胜
4. 棋盘下满且无五子连珠则为平局

## 操作方法

- **落子**：在棋盘交叉点点击鼠标左键
- **重置游戏**：点击"重置游戏"按钮
- **退出游戏**：关闭窗口或按 Esc 键

## 核心类说明

### Board 类
- 管理棋盘状态

- 玩家切换管理

### MainWindow 类
- 主窗口界面
- 棋盘绘制
- 用户交互处理
