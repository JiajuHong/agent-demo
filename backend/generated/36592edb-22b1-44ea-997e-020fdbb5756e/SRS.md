# 需求规格说明书

## 1. 项目概述

### 1.1 项目名称
单词记忆大师 - 智能背单词小程序

### 1.2 项目简介
一个基于SpringBoot后端和UniApp前端的智能背单词小程序，集成网易有道词典API，提供多种学习模式和个性化记忆算法，帮助用户高效记忆英语单词。

### 1.3 目标用户
- 学生群体（四六级、考研、托福、雅思备考）
- 职场人士（商务英语、专业词汇学习）
- 英语爱好者（日常词汇积累）
- 语言学习者（多语言词汇记忆）

## 2. 功能需求

### 2.1 核心功能

#### 功能点 1：用户注册登录
- 描述：用户可以通过手机号或邮箱注册登录系统
- 优先级：高
- 前置条件：无
- 操作流程：
  1. 用户进入登录页面
  2. 选择注册或登录
  3. 输入手机号/邮箱和密码
  4. 完成验证
  5. 进入主页面
- 预期结果：用户成功登录，进入学习主界面

#### 功能点 2：词库管理
- 描述：集成网易有道词典API，支持多种词库分类
- 优先级：高
- 前置条件：用户已登录
- 操作流程：
  1. 用户选择词库分类（四六级、考研、托福等）
  2. 系统从网易API获取单词列表
  3. 展示单词详情（发音、释义、例句）
  4. 用户可收藏单词到个人词库
- 预期结果：用户可浏览和学习不同分类的单词

#### 功能点 3：单词学习
- 描述：提供多种学习模式帮助记忆单词
- 优先级：高
- 前置条件：用户已登录并选择词库
- 操作流程：
  1. 用户选择学习模式（卡片学习、选择题、拼写测试）
  2. 系统按记忆算法展示单词
  3. 用户进行学习交互
  4. 系统记录学习进度
- 预期结果：用户完成单词学习，系统更新记忆状态

#### 功能点 4：记忆算法
- 描述：基于艾宾浩斯记忆曲线的智能复习算法
- 优先级：高
- 前置条件：用户有学习记录
- 操作流程：
  1. 系统根据用户学习历史计算复习时间
  2. 在适当时机推送复习任务
  3. 根据复习效果调整下次复习时间
- 预期结果：提高单词记忆效率，减少遗忘

#### 功能点 5：测试评估
- 描述：多种测试模式检验学习效果
- 优先级：中
- 前置条件：用户已学习一定数量的单词
- 操作流程：
  1. 用户选择测试类型（选择题、填空题、听力测试）
  2. 系统生成测试题目
  3. 用户完成测试
  4. 系统评分并给出分析报告
- 预期结果：用户了解自己的学习效果，获得改进建议

#### 功能点 6：学习统计
- 描述：可视化展示学习进度和成果
- 优先级：中
- 前置条件：用户有学习记录
- 操作流程：
  1. 用户查看统计页面
  2. 系统展示学习时长、单词数量、正确率等数据
  3. 提供图表化展示（折线图、柱状图）
  4. 生成学习报告
- 预期结果：用户清晰了解学习进度和效果

#### 功能点 7：个人词库
- 描述：用户可管理自己的单词收藏
- 优先级：中
- 前置条件：用户已登录
- 操作流程：
  1. 用户查看收藏的单词
  2. 可对单词进行分类标记
  3. 可导出单词列表
  4. 可删除不需要的单词
- 预期结果：用户拥有个性化的单词学习库

### 2.2 用户交互

#### 用户角色
| 角色 | 描述 | 权限 |
|------|------|------|
| 普通用户 | 使用小程序学习单词 | 注册登录、学习单词、查看统计、管理个人词库 |
| 系统管理员 | 管理系统后台 | 用户管理、词库管理、数据统计、系统配置 |

#### 界面原型（文字描述）
1. **登录注册页**：简洁的表单，支持手机号/邮箱登录注册
2. **首页**：学习进度概览、快速开始按钮、今日任务
3. **学习页**：单词卡片展示区、发音按钮、释义区域、学习控制按钮
4. **词库页**：词库分类列表、搜索功能、单词列表
5. **测试页**：测试题目展示、选项区域、提交按钮
6. **统计页**：学习数据图表、成就徽章、学习报告
7. **个人中心**：用户信息、设置选项、学习记录

## 3. 数据需求

### 3.1 数据实体

| 实体名称 | 说明 | 主要属性 |
|----------|------|----------|
| 用户 | 系统用户信息 | id, username, password, email, phone, avatar, created_at |
| 单词 | 单词基本信息 | id, word, phonetic, definition, example, audio_url, difficulty |
| 词库分类 | 单词分类 | id, name, description, level, word_count |
| 学习记录 | 用户学习历史 | id, user_id, word_id, learning_time, status, next_review_time |
| 测试记录 | 用户测试结果 | id, user_id, test_type, score, duration, created_at |
| 收藏单词 | 用户收藏的单词 | id, user_id, word_id, tags, created_at |
| 学习统计 | 用户学习统计数据 | id, user_id, total_words, learned_words, total_time, streak_days |

### 3.2 数据操作

| 操作 | 输入 | 输出 | 约束 |
|------|------|------|------|
| 用户注册 | 用户名、密码、邮箱/手机号 | 用户ID、token | 用户名唯一，密码强度要求 |
| 用户登录 | 用户名/邮箱/手机号、密码 | 用户信息、token | 验证用户存在且密码正确 |
| 获取单词 | 词库ID、页码、每页数量 | 单词列表 | 支持分页和筛选 |
| 学习单词 | 用户ID、单词ID、学习状态 | 学习记录ID | 记录学习时间和状态 |
| 开始测试 | 用户ID、测试类型、单词数量 | 测试题目列表 | 根据用户水平生成题目 |
| 提交测试 | 用户ID、测试ID、答案列表 | 测试得分、分析报告 | 计算正确率和得分 |
| 收藏单词 | 用户ID、单词ID | 收藏记录ID | 避免重复收藏 |
| 获取统计 | 用户ID、时间范围 | 统计数据、图表数据 | 支持按日、周、月统计 |

## 4. 非功能需求

### 4.1 性能需求
- 响应时间：API响应时间 < 500ms
- 并发能力：支持1000并发用户
- 吞吐量：QPS > 100

### 4.2 安全需求
- 认证方式：JWT Token
- 权限控制：接口级别权限验证
- 数据保护：密码加密存储，敏感信息脱敏

### 4.3 部署需求
- 运行环境：Docker容器化部署
- 依赖服务：MySQL 8.0+、Redis缓存
- 外部API：网易有道词典API

### 4.4 兼容性需求
- 前端：支持微信小程序、H5、App多端
- 后端：支持Linux/Windows服务器
- 数据库：MySQL 5.7+兼容
