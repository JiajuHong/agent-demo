交互说明

  • 悬停打开盖子 - 将鼠标悬停在耳机盒上，盖子会自动打开
  • 拖拽旋转 - 点击并拖拽可以旋转查看耳机盒的各个角度
  • 充电指示灯 - 指示灯有呼吸灯效果，模拟充电状态
  • 耳机细节 - 盖子打开后可以看到内部的耳机细节
  • 纯 CSS 实现 - 所有效果仅使用 HTML 和 CSS，无 JavaScript
