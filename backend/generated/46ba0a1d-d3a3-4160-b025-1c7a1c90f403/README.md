# 智能抽烟计时器 🚭

一个基于Web的抽烟计时器，帮助用户控制抽烟频率，记录抽烟习惯，并提供戒烟鼓励的健康管理工具。

## ✨ 功能特性

### 🕒 核心功能
- **智能计时器**：准确记录距离上次抽烟的时间
- **一键记录**：简单点击记录每次抽烟
- **目标设置**：自定义抽烟间隔目标
- **进度跟踪**：实时显示目标达成进度

### 📊 数据统计
- **今日统计**：显示今日抽烟次数、平均间隔、最长间隔
- **节省金额**：根据抽烟次数计算节省的金额
- **趋势图表**：可视化展示抽烟间隔变化趋势
- **历史记录**：查看最近的抽烟记录

### 💪 健康管理
- **健康进度**：显示健康改善进度
- **成就系统**：解锁连续达标成就（青铜、白银、黄金、钻石）
- **健康小贴士**：提供戒烟相关的健康知识
- **健康报告**：生成个性化的健康改善建议

### ⚙️ 个性化设置
- **主题切换**：支持浅色、深色、健康三种主题
- **目标调整**：灵活设置抽烟间隔目标
- **提醒设置**：声音提醒和桌面通知
- **价格设置**：自定义香烟价格和每包支数

## 🎯 使用方法

### 基本操作
1. **启动计时器**：点击"开始计时"按钮
2. **记录抽烟**：当您想抽烟时，点击"记录抽烟"按钮
3. **查看统计**：在统计面板查看今日数据
4. **设置目标**：在设置面板调整目标间隔

### 键盘快捷键
- **空格键**：开始/暂停计时器
- **R键**：记录抽烟
- **T键**：切换主题
- **Ctrl+H**：显示帮助
- **Ctrl+E**：导出数据

### 数据管理
- **导出数据**：点击底部"导出数据"按钮，保存为JSON文件
- **导入数据**：点击"导入数据"按钮，选择之前导出的JSON文件
- **清除数据**：点击"清除数据"按钮，清空所有记录（谨慎操作）

## 🛠️ 开发说明

### 模块架构
应用采用模块化设计，各模块职责明确：
- **EventBus**：模块间通信
- **Storage**：数据持久化
- **Timer**：计时器核心逻辑
- **Data**：数据统计和管理
- **Settings**：用户设置管理
- **Health**：健康信息计算
- **UI**：用户界面管理
- **ThemeManager**：主题管理

### 事件驱动
使用事件总线进行模块间通信，主要事件类型：
- `timer:*`：计时器相关事件
- `data:*`：数据相关事件
- `settings:*`：设置相关事件
- `health:*`：健康相关事件
- `ui:*`：UI相关事件

### 数据存储
使用LocalStorage存储以下数据：
- 用户设置
- 抽烟记录
- 统计数据
- 成就状态
