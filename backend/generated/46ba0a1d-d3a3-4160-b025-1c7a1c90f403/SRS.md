# 需求规格说明书

## 1. 项目概述

### 1.1 项目名称
智能抽烟计时器

### 1.2 项目简介
一个基于Web的抽烟计时器，帮助用户控制抽烟频率，记录抽烟习惯，并提供戒烟鼓励的健康管理工具。通过可视化计时、数据统计和健康提醒，帮助用户逐步减少抽烟量。

### 1.3 目标用户
- 希望控制抽烟频率的烟民
- 正在尝试戒烟的用户
- 关注健康生活方式的用户

## 2. 功能需求

### 2.1 核心功能

#### 功能点 1：计时器控制
- **描述**：用户可以启动/暂停/重置计时器，记录每次抽烟的时间间隔
- **优先级**：高
- **前置条件**：用户访问网页
- **操作流程**：
  1. 用户点击"开始计时"按钮
  2. 计时器开始运行，显示距离上次抽烟的时间
  3. 用户再次抽烟时，点击"记录抽烟"按钮
  4. 计时器重置，开始新一轮计时
- **预期结果**：准确记录抽烟间隔时间，帮助用户控制抽烟频率

#### 功能点 2：数据统计
- **描述**：统计用户的抽烟数据，包括今日次数、平均间隔、最长间隔等
- **优先级**：中
- **前置条件**：用户至少记录了一次抽烟
- **操作流程**：
  1. 系统自动记录每次抽烟的时间
  2. 计算并显示统计数据
  3. 提供数据可视化图表
- **预期结果**：用户能够清晰了解自己的抽烟习惯和进步情况

#### 功能点 3：目标设置与提醒
- **描述**：用户可以设置抽烟间隔目标，系统提供提醒功能
- **优先级**：中
- **前置条件**：用户设置了目标间隔
- **操作流程**：
  1. 用户设置期望的抽烟间隔（如2小时）
  2. 当达到目标间隔时，系统显示鼓励信息
  3. 提供声音/视觉提醒选项
- **预期结果**：帮助用户逐步延长抽烟间隔，达到戒烟目标

#### 功能点 4：健康信息展示
- **描述**：显示戒烟相关的健康信息和节省金额
- **优先级**：低
- **前置条件**：用户记录了抽烟数据
- **操作流程**：
  1. 根据抽烟次数计算节省的金额
  2. 显示健康改善信息（如肺部恢复时间）
  3. 提供戒烟小贴士
- **预期结果**：激励用户坚持控制抽烟，关注健康收益

### 2.2 用户交互

#### 用户角色
| 角色 | 描述 | 权限 |
|------|------|------|
| 普通用户 | 使用计时器控制抽烟频率 | 使用所有计时功能、查看统计数据、设置目标 |

#### 界面原型（文字描述）
1. **主计时界面**：
   - 大型数字计时器显示当前间隔时间
   - 醒目的"记录抽烟"按钮
   - 计时器状态指示（运行中/已暂停）
   
2. **数据统计面板**：
   - 今日抽烟次数
   - 平均间隔时间
   - 最长间隔时间
   - 节省金额计算
   
3. **控制面板**：
   - 开始/暂停/重置按钮
   - 目标间隔设置滑块
   - 提醒开关
   
4. **健康信息区**：
   - 健康改善进度条
   - 戒烟小贴士轮播
   - 成就徽章展示

## 3. 数据需求

### 3.1 数据实体

| 实体名称 | 说明 | 主要属性 |
|----------|------|----------|
| 抽烟记录 | 记录每次抽烟的时间 | id, timestamp, interval |
| 用户设置 | 用户个性化设置 | target_interval, enable_sound, theme |
| 统计数据 | 汇总统计数据 | today_count, avg_interval, max_interval, saved_money |

### 3.2 数据操作

| 操作 | 输入 | 输出 | 约束 |
|------|------|------|------|
| 记录抽烟 | 当前时间 | 新的抽烟记录 | 至少间隔1分钟 |
| 获取统计 | 日期范围 | 统计数据 | 最多查询30天数据 |
| 更新设置 | 设置参数 | 更新后的设置 | 参数在有效范围内 |

## 4. 非功能需求

### 4.1 性能需求
- 响应时间：页面加载时间 < 2秒
- 并发能力：支持单个用户使用
- 计时精度：毫秒级计时精度

### 4.2 安全需求
- 数据存储：使用浏览器本地存储（LocalStorage）
- 隐私保护：所有数据存储在用户本地设备
- 无用户认证：无需登录，保护用户隐私

### 4.3 部署需求
- 运行环境：现代浏览器（Chrome/Firefox/Safari/Edge）
- 依赖服务：纯前端应用，无需后端服务
- 移动端适配：响应式设计，支持手机和平板

## 5. 验收标准

### 5.1 功能验收
- [ ] 计时器可以准确计时，显示格式正确
- [ ] "记录抽烟"按钮可以正确重置计时器
- [ ] 统计数据能够正确计算和显示
- [ ] 目标设置功能可以正常工作
- [ ] 健康信息能够根据数据动态更新

### 5.2 质量标准
- 页面加载时间 < 2秒
- 支持移动端和桌面端浏览器
- 代码无JavaScript错误
- 界面美观，用户体验良好
- 数据持久化（关闭浏览器后数据不丢失）
