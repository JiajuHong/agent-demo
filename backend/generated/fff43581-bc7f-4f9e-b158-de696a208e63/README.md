# 简单命令行计算器

一个基于Python的命令行交互式计算器，支持基本的四则运算和常用数学函数。

## 功能特性

- ✅ **基本四则运算**：支持加减乘除
- ✅ **运算符优先级**：自动处理运算顺序
- ✅ **括号支持**：支持多层括号嵌套
- ✅ **数学函数**：支持常用数学函数（sqrt, sin, cos, log等）
- ✅ **常量支持**：pi, e 等数学常量
- ✅ **安全计算**：输入验证和安全环境
- ✅ **错误处理**：友好的错误提示
- ✅ **连续计算**：支持连续多次计算

## 快速开始

### 运行要求
- Python 3.6 或更高版本
- 无需安装额外依赖

### 运行方式

1. **直接运行**：
   ```bash
   python calculator.py
   ```

2. **或添加执行权限后运行**：
   ```bash
   chmod +x calculator.py
   ./calculator.py
   ```

## 程序结构

```
calculator.py
├── CalculatorEngine 类 - 计算引擎
│   ├── calculate() - 执行计算
│   └── _create_safe_environment() - 创建安全环境
├── InputValidator 类 - 输入验证
│   ├── validate_expression() - 验证表达式
│   └── _check_parentheses() - 检查括号匹配
├── UserInterface 类 - 用户界面
│   ├── display_welcome() - 显示欢迎信息
│   ├── get_user_input() - 获取用户输入
│   ├── display_result() - 显示结果
│   ├── display_error() - 显示错误
│   └── ask_to_continue() - 询问是否继续
└── main() - 主程序入口
```

## 安全特性

1. **输入验证**：
   - 检查表达式长度（不超过1000字符）
   - 过滤危险关键字
   - 验证字符合法性
   - 检查括号匹配

2. **安全计算环境**：
   - 限制可用的函数和变量
   - 禁止危险的内置函数
   - 使用受限的命名空间

3. **错误处理**：
   - 语法错误提示
   - 除零错误处理
   - 类型错误处理
   - 友好的错误信息

## 退出程序

有以下几种方式可以退出程序：

1. 在输入表达式时输入：`q`, `quit`, `exit`
2. 在询问是否继续时输入：`n`, `no`, `否`
3. 使用快捷键：`Ctrl+C` 或 `Ctrl+D`

## 扩展功能

如需扩展功能，可以修改以下部分：

1. **添加新函数**：在 `CalculatorEngine._create_safe_environment()` 中添加
2. **修改验证规则**：在 `InputValidator` 类中修改
3. **调整显示格式**：在 `UserInterface` 类中修改
