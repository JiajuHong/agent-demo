# 抽烟小助手 (Smoking Assistant)

一个简单实用的纯前端Web应用，帮助用户记录抽烟行为，跟踪抽烟次数和间隔时间，计算花费金额。

## 🌟 功能特点

- **记录抽烟**：一键记录每次抽烟行为
- **数据统计**：实时显示今日抽烟次数、花费金额、最近一次时间、平均间隔
- **进度跟踪**：可视化显示每日目标进度
- **历史记录**：查看今日所有抽烟记录
- **个性化设置**：自定义烟价和每日目标
- **本地存储**：数据保存在浏览器LocalStorage中
- **响应式设计**：适配手机、平板和电脑
- **无后端依赖**：纯前端实现，无需服务器

## 📱 使用说明

### 主要功能

1. **记录抽烟**
   - 点击"记录抽烟"按钮记录一次抽烟
   - 支持快捷键：空格键

2. **查看统计**
   - 今日抽烟次数
   - 花费金额（根据设置的烟价计算）
   - 最近一次抽烟时间
   - 平均抽烟间隔

3. **管理数据**
   - 重置今日数据（清空当日记录）
   - 自动保存所有数据到LocalStorage

4. **个性化设置**
   - 设置每支烟价格
   - 设置每日抽烟目标
   - 设置自动保存

## 📊 统计计算

### 计算公式
- **花费金额** = 今日抽烟次数 × 每支烟价格
- **平均间隔** = 总间隔时间 ÷ (记录数 - 1)
- **目标进度** = (今日抽烟次数 ÷ 每日目标) × 100%

### 数据持久化
- 所有数据自动保存到LocalStorage
- 支持页面刷新后数据恢复
- 自动清理30天前的旧记录

## 🔒 隐私与安全

### 数据存储
- 所有数据存储在用户本地浏览器中
- 无服务器传输，保护用户隐私
- 数据不会上传到任何服务器

### 安全性
- 无用户认证需求
- 无敏感数据传输
- 本地数据处理

## 🚨 注意事项

1. **数据备份**：定期导出数据备份，防止浏览器数据被清除
2. **浏览器限制**：不同浏览器LocalStorage限制不同（通常5-10MB）
3. **隐私模式**：隐私浏览模式下LocalStorage可能被限制
4. **数据清理**：浏览器缓存清理可能删除应用数据
